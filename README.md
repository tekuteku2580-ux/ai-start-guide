# 自分だけのAIパートナーを作る　はじめの一歩

Claude Code を使って、自分専用のAIパートナー（話し相手・生活の相棒）を作るための、いちばん最初の準備です。
ここでは「GitHub のアカウントを作る」ところと「Claude Code を使えるようにする」ところだけを説明します。
作り方の本番は、準備ができたあとに招待される場所で、AIの先生がくわしく教えてくれます。

---

## GitHub って、こわくないよ

「GitHub」って名前を聞くと、プログラマーの難しい道具っぽくて、ちょっとこわく感じるかもしれません。でも大丈夫です。

- **ただの「ネットの上のフォルダ」です。** 写真を Google フォトや iCloud に置いておくのと同じで、ファイルを置いておける場所なだけ
- **自分でさわるのはほとんどアカウント作りだけ。** そのあとの難しい操作は、ぜんぶ Claude Code（AI）がやってくれます。「保存して」「スマホでも見られるようにして」と言うだけでOK
- **非公開にできます。** 自分のメモや日記を置いても、招待した人以外には見えません
- **こわしても大丈夫。** GitHub は変更の歴史を全部おぼえているので、まちがえても前の状態に戻せます
- **わからなくなったら、AIに聞けばいい。** 画面に出た英語をそのまま Claude Code に見せて「これ何？」と聞けば教えてくれます

---

## ステップ1　GitHub のアカウントを作る

GitHub は、ファイルをネット上に置いておける場所です。
パソコンとスマホの両方で同じAIパートナーを使うために必要になります。

1. ブラウザで https://github.com/signup を開く
2. メールアドレス・パスワード・ユーザー名を入れる
   - ユーザー名はあとで人に伝えるので、本名ではないものがおすすめ
3. 届いたメールの確認コードを入れて完了
4. 右上のアイコン → Settings → Password and authentication から、二段階認証（2FA）をオンにしておくと安心

## ステップ2　パソコンの準備（Windows の場合）

1. **Git を入れる**
   - https://git-scm.com/download/win からダウンロードして、そのままインストール（設定は全部そのままでOK）
2. **Claude Code を入れる**
   - https://claude.com/claude-code の手順にしたがってインストール
   - 起動したら、課金している Claude のアカウントでログイン
3. **GitHub CLI を入れる**（Claude Code が GitHub とやりとりするための道具）
   - https://cli.github.com/ からインストール
   - Claude Code に「GitHub にログインしたい」と言えば、やり方を教えてくれます

## ステップ3　招待を受ける

1. このページを教えてくれた人に、**GitHub のユーザー名**を伝える
2. GitHub から招待のメールが届くので、「Accept invitation」を押す
3. Claude Code に、招待された場所の名前を伝えて「これをパソコンに持ってきて、中身を読んで」と言う
4. あとは「AIパートナーってどうやって作るの？」と聞けば、先生が一から教えてくれます

## スマホで使うには

スマホでは Claude のアプリ（または claude.ai）から、GitHub につないで使います。
くわしいつなぎ方も、招待された場所の先生が教えてくれます。

---

わからないところがあったら、Claude Code にこのページの内容をそのまま見せて「これどういうこと？」と聞けばOKです。
